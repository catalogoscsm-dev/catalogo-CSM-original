Como funcionar a catalogação de imagens

Conceito geral

Cada produto no banco de dados tem um campo pagina — o número da página onde ele aparece no PDF do catálogo. Usamos esse número para saber qual imagem pertence a qual produto.

Você baixa as imagens do PDF e salva com nomes específicos. O script lê esses nomes, identifica o número da página, localiza o produto correspondente no banco e atualiza as fotos automaticamente.

---
Como nomear os arquivos

Existem dois tipos de imagem:

pag N.png — foto principal da página N
- Geralmente é a foto ambiente/completa do produto, como aparece no catálogo
- Vira a galeria (foto secundária) quando também existe uma versão recortada

pag recorte N.png — foto recortada da página N
- É a imagem limpa do produto, sem texto ou elementos ao redor
- Sempre vira a capa do card (foto principal)

▎ Substitua N pelo número da página. A extensão pode ser .jpg, .jpeg, .png ou .webp.

Exemplos práticos:

┌─────────────────────────────────────┬─────────────────────────────────────────────────┐
│            Arquivo salvo            │               O que o script faz                │
├─────────────────────────────────────┼─────────────────────────────────────────────────┤
│ pag 17.png                          │ Capa do produto que está na página 17           │
├─────────────────────────────────────┼─────────────────────────────────────────────────┤
│ pag recorte 17.png                  │ Capa do produto na pág. 17 (tem prioridade)     │
├─────────────────────────────────────┼─────────────────────────────────────────────────┤
│ pag 17.png + pag recorte 17.png     │ Recorte vira capa, página inteira vira galeria  │
├─────────────────────────────────────┼─────────────────────────────────────────────────┤
│ pag 18.png (sem produto na pág. 18) │ Galeria do produto mais próximo (pág. 17 ou 19) │
└─────────────────────────────────────┴─────────────────────────────────────────────────┘

---
Regras de prioridade

1. Se existe pag recorte N → ela é sempre a capa
2. Se existe pag N junto com pag recorte N → pag N vira galeria
3. Se existe só pag N (sem recorte) → ela é a capa
4. Se a página N não tem produto cadastrado → o script busca o produto mais próximo (N+1, N-1, N+2...) e adiciona a imagem como galeria dele

---
Os dois scripts

Script 1 — importar-imagens.js

Quando usar: você baixou novas imagens e quer importá-las para o catálogo.

node scripts/importar-imagens.js "NOME DO CATÁLOGO" "PASTA COM AS FOTOS"

Exemplo:
node scripts/importar-imagens.js "ABV 2025" "C:\Users\joao\Desktop\fotos abv"

O que ele faz:

O que ele faz:
- Lê os arquivos da pasta que você indicou
- Copia cada imagem para a pasta correta do catálogo
- Atualiza o banco de dados com os caminhos das fotos

---
Script 2 — resinkar-catalogo.js

Quando usar: as imagens já estão na pasta do catálogo (seja por importação anterior ou qualquer outro motivo) e você quer religar tudo ao banco.

node scripts/resinkar-catalogo.js "NOME DO CATÁLOGO"

Exemplo:
node scripts/resinkar-catalogo.js "ABV 2025"

Flags opcionais:
- --force → reprocessa mesmo os produtos que já têm foto

O que ele faz:
- Lê os arquivos que já estão em imagens dos produtos
- Reconhece automaticamente qualquer convenção de nome (novo padrão, padrão antigo, etc.)
- Só toca em produtos que ainda não têm foto (a menos que use --force)

---
Fluxo completo de trabalho

1. Abrir o PDF do catálogo

2. Para cada produto:
   → Salvar a foto da página como:     pag N.png
   → Salvar a foto recortada como:     pag recorte N.png
     (onde N = número da página no PDF)

3. Juntar todos os arquivos em uma pasta (ex: Desktop\fotos abv)

4. Rodar o script de importação:
   node scripts/importar-imagens.js "ABV 2025" "C:\...\fotos abv"

5. Conferir no site — cada card já aparece com a foto correta

---
O que o script faz automaticamente

- Copia as imagens para o lugar certo (não precisa mover manualmente)
- Não duplica fotos se você rodar duas vezes com o mesmo arquivo
- Preserva fotos de importações anteriores que não foram substituídas
- Associa páginas sem produto ao produto vizinho mais próximo
- Funciona com qualquer extensão de imagem (jpg, png, webp…)

O QUE O CLAUDE FAZ AUTOMATICAMENTE
------------------------------------
Quando você avisa "acabei de adicionar mais imagens", o Claude:

     - Converte .jfif → .jpg

  2. importar-subpastas.cjs
     - Copia as imagens para public/imagens/
     - Atualiza o banco de dados com as URLs
     - Atribui as fotos a todos os produtos daquela página

  3. export-data.js
     - Gera o arquivo data/static-data.json usado pelo site

  4. git commit + git push
     - Sobe tudo para o GitHub → Vercel redeploy automático


PÁGINAS COM MÚLTIPLOS PRODUTOS
--------------------------------
Quando a pasta tem mais de um produto (ex: pag 14 = Cadeira Luxor + Mesa Louvre),
as mesmas imagens são atribuídas a ambos os produtos automaticamente.

Para páginas ambiente (28, 30, 34, 38) — fotos de sala mostrando vários móveis juntos —
as imagens também são distribuídas para todos os produtos listados naquela página.

NOVO FLUXO — CATÁLOGOS SIMPLIFICADOS (VITRINE)
=============================================================

FILOSOFIA
----------
O catálogo é uma vitrine de luxo — não um manual técnico completo.
Mas páginas completamente vazias prejudicam a busca e a experiência do cliente.

EQUILÍBRIO IDEAL POR PRODUTO:
  ✓ Nome do produto (exato, como aparece no catálogo)
  ✓ Categoria (Sofá, Poltrona, Mesa, etc.)
  ✓ Material principal (1 linha — ex: "Estrutura em lyptus, pés em Tauarí")
  ✓ Dimensão geral (ex: "230 x 95 x 78 cm" — só a versão padrão)
  ✓ Acabamentos disponíveis (ex: "Tecido, couro, veludo") — se constar no PDF
  ✗ Tabelas de configuração completas → desnecessário
  ✗ Especificações de engenharia → desnecessário

POR QUE ESSE EQUILÍBRIO?
  - Material e dimensão geral ajudam o cliente a filtrar antes de contatar o vendedor
  - Palavras-chave como "couro", "lyptus", "alumínio" aparecem na busca do site
  - A ficha fica visualmente preenchida sem exigir horas de extração por PDF
  - Detalhes avançados (configurações, módulos, preços) ficam com os vendedores

PROMPT UNIVERSAL DE CATALOGAÇÃO (use este para todos os PDFs)
--------------------------------------------------------------
Você é um especialista em catalogação de móveis e decoração de alto padrão.
Analise este catálogo PDF página por página e extraia os dados de cada produto.

Retorne uma tabela com exatamente estas colunas:
| Página | Nome | Categoria | Material | Dimensão | Acabamentos | Descrição |

REGRAS POR COLUNA:

▸ Página
  Número da página onde o produto aparece.
  Se um produto aparece em mais de uma página, use a primeira.

▸ Nome
  Exatamente como aparece no catálogo — sem traduzir, sem abreviar.
  Se o catálogo usar código (ex: "MOD-042"), use o código completo.

▸ Categoria
  Uma única palavra que classifica o produto. Use sempre em português:
  Sofá, Poltrona, Cadeira, Mesa, Aparador, Buffet, Rack, Estante,
  Cama, Criado-mudo, Banqueta, Puff, Chaise, Recamier, Luminária,
  Tapete, Espelho, Prateleira, Pendente, Armário, Cômodas, Biombo.
  Se não se encaixar em nenhuma, use a palavra mais próxima.

▸ Material
  Estrutura + revestimento em até 2 linhas curtas.
  Inclua: madeira, metal, tecido, couro, fibra, espuma, etc.
  Exemplo: "Estrutura em MDF lacado, pés em alumínio fosco, assento em espuma D33"
  Se não constar no catálogo, deixe em branco.

▸ Dimensão
  Apenas a medida principal (versão padrão ou menor disponível).
  Formato: "L x P x A cm" — converta para cm se estiver em metros.
  Ignore tabelas de módulos, composições e variações — só a dimensão base.
  Se não constar, deixe em branco.

▸ Acabamentos
  Opções de cor, revestimento ou material disponíveis, em até 1 linha.
  Exemplo: "Tecido, veludo, couro natural, couro sintético"
  Se não constar, deixe em branco.

▸ Descrição
  1 frase destacando o que torna o produto especial ou diferente.
  Foque em estilo, design ou característica marcante.
  Exemplo: "Design escandinavo com costuras aparentes e pés palito em madeira maciça."
  Se não houver nada relevante além do básico, deixe em branco.

REGRAS GERAIS:
  • Ignore: capa, contracapa, índice, páginas institucionais, páginas sem produto.
  • Uma página com variações (cores, tamanhos) do mesmo produto = 1 linha na tabela.
  • Uma página com produtos diferentes = 1 linha por produto.
  • Quando a informação não estiver clara ou visível no PDF, deixe o campo em branco.
    Não invente nem suponha dados que não estejam explícitos.
  • Priorize informações que um cliente usaria para decidir uma compra.

Retorne APENAS a tabela, sem introdução, sem comentários, sem texto adicional.
